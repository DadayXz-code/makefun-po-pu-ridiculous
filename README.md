A Python program that writes a single-sentence startup pitch — retired greyhounds rented out as professional couch-warmers for lonely remote workers — to `entry.txt`, for make.fun's "Ridiculous at First Glance, Real by the Second" bounty.

## Run it

```sh
python3 main.py
```

The program validates the pitch first (one sentence, 1–200 characters,
not only white space) and writes it to `output/entry.txt`. Pass a
different directory as the first argument, or set `MAKEFUN_OUTPUT_DIR`,
to change where the file lands. The output is byte-identical on every run.

## The pitch

> We rent retired greyhounds as professional couch-warmers for lonely remote workers: $29 a month, a warm dog on your feet all day, and your burnout drops faster than your heating bill.

Ridiculous at first glance — a dog as office furniture — and real by the
second: retired racers need homes, remote workers pay for warmth and
company, and $29 a month is cheaper than therapy or a heating bill.
